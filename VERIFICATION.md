## 🚀 Quick Start

### Installation (3 commands)

```bash
git clone https://github.com/krish-developer010/weblens.git
cd weblens
npm install
```

### Run Development Server

```bash
npm run dev
```

Opens at: `http://localhost:5173`

### Production Build

```bash
npm run build
```

Output in: `dist/` folder
